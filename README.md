# Tools
Tools that I have developed whilst preparing for CPTS/OSCP.

Currently, there are **two** tools in the repo:
- EnumDir; A Python based directory and subdomain bruteforcer, similar to DirBuster. Allows for custom wordlists, multi-threading, and saving results to different filetypes.
- Tina; A Python based AI network scanner that runs on Ollama. This tool has the ability to run basic enumeration techniques on a target scope, and provide comprehensive output about it's findings, and the next steps you should take.


More tools coming soon!
